## 二、设计令牌（Design Tokens）

### 2.1 色彩（OKLCH 思维，实现用 HEX）

| 角色 | 名称 | HEX | 用途 |
|---|---|---|---|
| 背景 | Paper | `#F6F4EE` | 页面底、图标槽（暖砂纸色，非纯白/纯灰） |
| 主色 | Pine | `#23463B` | 导航栏、主按钮、主要数字、Logo 色 |
| 主色浅 | Pine-2 | `#2F5A4C` | 主色 hover / 次级强调 |
| 破戒 | Clay | `#C0533B` | 破戒色块、超限状态、破戒次数（赤陶砖红，非刺眼纯红） |
| 破戒浅 | Clay-soft | `#F4E3DE` | 破戒标签底色 |
| 未破戒 | Sage | `#5C8C6A` | 未破戒色块、正常状态（鼠尾草绿） |
| 未破戒浅 | Sage-soft | `#E7F0E9` | 已过未破戒日、正常标签底 |
| 未破戒文字 | Sage-ink | `#3F6B4E` | **绿底上的文字**（Sage 本身在暖白底仅 3.5，只能做色块） |
| 破戒文字 | Clay-ink | `#9A3B27` | **浅红底上的文字**（同上，Clay 在暖白底仅 4.2） |
| 今天 | Indigo | `#3E6FB0` | 今日高亮（靛蓝，需求指定"今天=蓝"） |
| 今天浅 | Indigo-soft | `#E5EDF7` | 今日浅底 |
| 灰态 | Mist | `#DCDAD2` | 起点前日期、虚线描边（暖灰，非冷灰） |
| 灰态浅 | Mist-soft | `#F0EFE9` | 月历未来格底、提示区 |
| 灰态中 | Mist-2 | `#D2CFC4` | 周视图未来格（无文字，需 1.5:1 可辨识度） |
| 文字 | Ink | `#1F2A26` | 主文字（深墨，非纯黑） |
| 文字次 | Sub | `#5F6B64` | 次要文字，**全站唯一一档次级灰**（白卡 5.56 / 纸底 5.06） |
| 文字装饰 | Faint | `#B4B2A9` | **仅装饰**：箭头、禁用态、起点前数字。不得用于承载信息的正文 |
| 描边 | Line | `#EBE8DF` | 卡片描边、分隔线 |

> **文字色只有两档**（Ink / Sub）。层级靠字号与字重区分，不靠继续把灰调浅——暖纸底上要满足 4.5:1，可用的灰差最多只能容纳两档，第三档必然不达标。

**60-30-10 配比**：60% Paper/白底 + 30% 文字与描边 + 10% Pine/Clay 强调色。强调色只用于关键动作与状态，防止滥用失效。

### 2.2 字体

- 字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Segoe UI", sans-serif`（系统字体，加载快、可读性强，符合小程序性能约束）
- 数字：全部启用 `font-variant-numeric: tabular-nums; letter-spacing:-.02em`，保证统计数字纵向对齐
- 字号层级：**7 档，全部走令牌**，禁止在页面里写裸 rpx 字号。图标与 emoji 的尺寸不属于此体系，保持裸 rpx。

| 令牌 | 大小 | 设计稿 px | 用途 |
|---|---|---|---|
| `--t-num` | 80rpx | 34px | 主数值：当前未破戒天数、累计破戒 |
| `--t-num-2` | 56rpx | 24px | 次数值：问候语、卡片内次要大数 |
| `--t-h` | 44rpx | 19px | 卡片标题、指标数值 |
| `--t-h2` | 36rpx | 15px | 列表主文本、区块标题 |
| `--t-body` | 32rpx | 14px | 正文、表单输入、主按钮 |
| `--t-sub` | 28rpx | 12px | 辅助说明、meta、图例、标签 |
| `--t-cap` | 24rpx | 10px | 最小说明、单位、星期 |

> 收敛原则：设计稿 px × 2.36 逐项换算会产出 31/33/35/47 这类相差 1–2rpx 的值，它们不是设计决策，是实现痕迹。全部就近吸附到上表七档。

- 仅用两种字重：400（常规）、600/700（强调）。避免中间字重造成层级浑浊。

### 2.3 间距与圆角

- 基准：4pt（4 / 8 / 12 / 16 / 24 / 32 / 48）
- 卡片内边距：32rpx；卡片间距：24rpx；页面左右边距：32rpx
- 圆角：卡片 32rpx（16px）、按钮/小元素 20rpx（10px）、胶囊标签 999rpx
- 阴影：极轻 `0 4rpx 24rpx rgba(31,42,38,.05)`，能看见就说明太重
- 触摸目标：所有可点元素 ≥ 88rpx（44px）

## 三、核心组件规范

### 3.1 记录卡（首页主组件）

字段布局自上而下：① emoji+标题 / 状态徽章 → ② 副标题 → ③ 大号已戒天数 → ④ 一周五色条 → ⑤ 周期破戒次数+记录按钮。

- A4 状态：`正常`（Sage-soft 底 / Sage 字）、`已超限`（Clay-soft 底 / Clay 字）
- 卡片可点击进单卡统计；「记一次」按钮独立事件，不冒泡

### 3.2 一周状态条（A3，五态）

| 状态 | 色值 | 附加形状线索 | 语义 |
|---|---|---|---|
| 破戒日 | Clay `#C0533B` | 实心 | 有破戒记录，次数越多色越深 |
| 已过未破戒 | Sage-mid `#7FBD91` | 实心 | 已发生但未破戒 |
| 今天 | Indigo `#3E6FB0` | **内描边 3rpx 白圈** | 当前日，最高亮 |
| 未来 | Mist-2 `#D2CFC4` | 实心 | 今天之后 |
| 起点前 | 透明 | **1rpx 虚线描边** | 早于 C4 开始日期 |

> **形状冗余是必需的，不是装饰**：破戒红与今天蓝的亮度比只有 1.11，红绿也只有 2.11，仅靠色相时色觉障碍用户无法区分。因此今天加内描边、起点前用虚线，四态在灰度下也能分辨。

### 3.3 月历破戒图（单卡统计）

- 周一为首列；每格正方形；五种状态色同一周状态条
- 9 号（多次破戒）用加深的 Clay-2 `#9C3F2C` 表达次数层级
- 底部固定图例，点击日期弹出当日次数与备注

### 3.4 数据展示

- 总览数字卡：标签在上、大数在下；主指标（当前连续未破戒）用整行 Pine 反白大卡强调
- 柱状图（6 月趋势）：Pine 柱，超过阈值的月份用 Clay 标记
- 条形图（戒断目标对比）：Sage 条，最高者用 Clay 突出

## 四、六页设计说明

| 页面 | 核心设计决策 |
|---|---|
| 01 首页 | 顶部问候给情绪锚点；已戒天数做成视觉焦点（大号 tabular 数字）；卡片信息密度控制在一屏可读；空态引导文案"还没有戒断目标，点此创建第一个" |
| 02 记录页 | 顶部戒断目标条明确"在给谁记录"；日期下方常驻"最早可选"提示（落实 C4 起点约束）；次数用 stepper 防手误；备注下方说明"同日多次自动累加"；保存按钮文案避免"打卡"歧义 |
| 03 戒断目标管理 | 卡片内直接放编辑/排序图标；新增用虚线卡片降低心理门槛；编辑表单内嵌展示（图标/标题/副标题/C4/C5）；C4 日期选择器禁用晚于最早破戒记录的日期 |
| 04 单卡统计 | 6 项指标用 3×2 网格，一屏看全；月历占据下半屏，五态着色直观；"记录明细"作为指标格之一，点击进入明细页 |
| 05 记录明细 | 月份筛选置顶；日期与内容用左侧竖线分隔；破戒次数用 Clay 强调；每条独立删除按钮（二次确认在交互层实现） |
| 06 总体统计 | "当前连续未破戒"用整行反白大卡作为第一视觉；4 项总览后接两张月度图；图形遵循"量（趋势）+ 对比（戒断目标）"两维度，不含已移除的达成率 |

## 五、可访问性与质量

- 对比度（WCAG AA）：文字一律 ≥ 4.5:1，图形色块 ≥ 1.5:1。实测值见 `tools/audit-contrast.js`，该脚本直接读 `app.wxss` 令牌，可随时回归
- 文字色只有 Ink / Sub 两档，第三档 Faint 退为装饰色——暖纸底上满足 4.5:1 的灰差放不下三档
- 非色彩通道：今天格内描边、起点前虚线、状态徽章配文字、破戒次数配数字，满足 WCAG 1.4.1
- 触摸目标 ≥ 44px：视觉尺寸不够的按钮（71rpx 图标按钮、文字型删除/取消）用 `::after` 扩热区，视觉不变
- 所有可点元素必须有 `hover-class="is-pressed"`，否则点了没反应，用户会以为没点上
- 浅色主题：遵循微信小程序习惯，未做深色模式（个人工具，避免维护双主题成本）

## 六、交付给开发的注意事项

1. 原型为**静态高保真示意**，交互与统计口径以需求文档 v1.3 为准
2. 所有色值、字号、圆角已在第二章列出，可直接转写为 WXSS 变量
3. 五态色块逻辑由 `utils/stats.js` 的 `weekCells` / `monthCells` 输出 `state` 字段驱动
4. 数字展示务必加 `font-variant-numeric: tabular-nums`，否则跳动
