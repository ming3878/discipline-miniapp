## 二、背景与目标

**一句话定位**：这是一款「戒断型」自律工具。它不记录"完成了什么"，只记录"**破戒了几次**"，以"不超过上限"为达成标准——记录一次即破戒一次，没有记录就是没破戒。

| 项 | 内容 |
|---|---|
| 要解决的问题 | 用户需要对多个戒断主题（如戒烟、戒游戏、戒熬夜）的破戒行为做轻量记录，并直观看到"坚持了多久、这周破戒几次、有没有超标" |
| 目标用户 | 用户本人 + 小范围试用朋友（各自独立记录，本期不做互动） |
| 成功指标（建议，待确认） | ① 单次打卡路径 ≤ 3 次点击；② 7 日留存 ≥ 25%；③ 记录卡信息一屏可读，无需滚动 |

## 三、名词与术语

| 术语 | 定义 |
|---|---|
| 主题 / 记录卡 | 一个戒断对象（如"戒烟"），是记录与统计的基本单元 |
| 破戒 | 一次违反自律的行为。**记录一次 = 破戒一次；无记录 = 未破戒** |
| 破戒次数 | 某条记录或某周期内累计的破戒数量 |
| 上限 X 次 | 目标周期内允许的最大破戒次数。**超过（> X）判为失败；等于（= X）算达成** |
| 目标周期 | 每天 / 每周 / 每月三选一，决定 A6 与达成判定的统计口径 |
| 当前周期 | 根据目标周期动态确定的统计区间（今日 / 本周 / 本月） |

## 四、需求范围

**本期包含**
- 记录卡列表（7 个字段展示）
- 破戒记录页（日期可调、次数、备注，同日多次叠加）
- 主题卡的新增与编辑
- 统计模块（建议方案见第五章，范围待确认）

**本期不包含（明确排除）**
- 账号体系、登录注册
- 好友互动、排行榜、分享（个人主体审核红线，且用户未提出）
- 定时提醒 / 推送
- 记录的编辑（只做删除，见 FR-06）
- 数据导出

## 五、统计维度建议（待用户拍板）

用户暂未确定统计展示内容，以下为推荐方案。**MVP 建议做「方案 A」，后续按数据积累迭代。**

| 方案 | 内容 | 成本 | 价值 | 建议 |
|---|---|---|---|---|
| **A 精简总览（推荐 MVP）** | 4 个总览数字卡 + 近 8 周破戒趋势图 + 本月主题破戒排行 | 低 | 高：回答"整体是否在变好" | ✅ 本期做 |
| B 深度分析 | 在 A 基础上加月历热力图、达成率统计、单主题趋势 | 中 | 中：适合有耐心的数据型用户 | 二期 |
| C 暂不做 | 统计页完全留空，只保留卡内 A3/A4/A6 | 极低 | 低：浪费已采集的数据 | ❌ 不建议 |

**方案 A 具体指标口径**

| 指标 | 口径 | 展示形式 |
|---|---|---|
| 当前连续未破戒天数 | 所有主题中，距最近一次破戒天数最大的值（无破戒则从"开始日期"起算） | 大数字卡 |
| 累计破戒总次数 | 全部主题全部记录的破戒次数之和 | 数字卡 |
| 进行中主题数 | 已创建主题总数 | 数字卡 |
| 坚持最久主题 | 当前连续未破戒天数最大的主题及其天数 | 数字卡 |
| 近 8 周破戒趋势 | 按自然周聚合，每周破戒次数 | 柱状图 / 折线图 |
| 本月主题排行 | 按主题统计本月破戒次数，降序 | 横向条形列表 |

> 待确认：是否采纳方案 A，或调整为 B / C。

## 六、用户角色与使用场景

**用户画像**（基于用户口述，非调研数据）：注重自我管理、希望量化戒断进度、愿意手动记录破戒行为的个人用户。

| 场景 | 描述 |
|---|---|
| S1 破戒后记录 | 用户破戒后，打开小程序 → 进入对应主题卡 → 点记录按钮 → 选日期（默认今天）→ 填次数与原因 → 保存 |
| S2 每日查看 | 用户打开首页，扫一眼各主题卡的 A3~A6，判断本周状态 |
| S3 新建主题 | 用户决定戒断新习惯 → 新增记录卡 → 填标题/副标题/emoji/开始日期/目标周期与上限 |
| S4 周期复盘 | 用户打开统计页，看近 8 周趋势与本月排行，判断是否需要收紧上限 |

## 七、功能需求（含验收标准）

### FR-01 记录卡列表（首页）

展示所有主题卡，每卡包含以下 7 个字段：

| 字段 | 编号 | 需求描述 | 验收标准（Given/When/Then） |
|---|---|---|---|
| 标题 + emoji | A1 | 卡片标题，emoji 显示在标题前 | Given 主题标题为"戒烟"、emoji 为 🚭；When 进入首页；Then 卡片首行显示"🚭 戒烟" |
| 副标题 | A2 | 主题的说明文字 | Given 副标题为"为了健康"；When 进入首页；Then 标题下方显示该文字；副标题为空时不占位 |
| 一周达成情况 | A3 | **固定展示周一至周日 7 天**，每天一个色块，**与目标周期无关**，仅表达"这周哪天破戒了" | Given 本周三、周五有破戒记录；When 进入首页；Then 周三/周五色块为破戒色，其余已过日期为未破戒色，未来日期为未来色 |
| 周期上限状态 | A4 | 显示当前周期是否超过上限，用状态标识（正常 / 已超限） | Given 周目标上限 3 次、本周已破戒 4 次；When 进入首页；Then 状态显示为"已超限" |
| 距上次破戒天数 | A5 | 距最近一次破戒记录的自然日天数；**无任何破戒记录时，从"开始日期"起算** | Given 最近破戒为 3 天前；When 进入首页；Then 显示"3 天"；Given 今天破戒；Then 显示"0 天" |
| 周期破戒次数 / 上限 | A6 | **跟随 C5 目标周期切换**：每天→今日次数/日上限；每周→本周次数/周上限；每月→本月次数/月上限 | Given 目标周期设为"每月"、上限 10 次、本月已破戒 6 次；When 进入首页；Then 显示"6 / 10" |
| 记录按钮 | A7 | 每张卡一个"记录"按钮，点击进入该主题的记录页 | Given 任一主题卡；When 点击记录按钮；Then 跳转至该主题的记录页 |

**A3 颜色语义建议**（待确认）：

| 日期状态 | 颜色建议 |
|---|---|
| 破戒日 | 红色系（破戒次数越多颜色越深） |
| 已过去的未破戒日 | 绿色 |
| 今天且未破戒 | 蓝色（高亮） |
| 未来日期 | 浅灰 |

### FR-02 破戒记录页

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| B1 | 打卡日期，默认当天，可调 | Given 今天是 2026-11-24；When 打开记录页；Then 日期默认 2026-11-24，且可改为其他日期 |
| B2 | 打卡数据 = 违反自律次数，默认 1，可修改 | Given 一次破戒；When 不修改次数；Then 记录为 1 次；改为 3 则记录 3 次 |
| B3 | 备注，自定义填写原因 | Given 用户输入"熬夜打游戏"；When 保存；Then 备注随记录存储并可在历史中查看 |
| 叠加规则 | 同一天可多次记录，破戒次数累加 | Given 同一天已记 1 次、再记 2 次；When 统计当日；Then 当日破戒次数为 3 次 |

### FR-03 新增 / 编辑记录卡

| 编号 | 字段 | 需求描述 | 验收标准 |
|---|---|---|---|
| C1 | 标题 | 必填，非空 | 标题为空时禁止保存并提示 |
| C2 | 副标题 | 选填 | 可留空 |
| C3 | emoji 图标 | 从 emoji 选择器中选，展示在标题前 | 选择后标题前正确渲染该 emoji |
| C4 | 从哪天开始戒 | 日期选择，默认今天 | 用于 A5 无破戒记录时的起算点 |
| C5 | 目标计算方式 | 每天 / 每周 / 每月 不超过 X 次（三选一），X 为正整数 | Given 选择"每月"、X=10；When 保存；Then A6 显示"本月累计/10"，达成判定按月口径 |

### FR-04 统计页

按第五章方案 A 实现（待确认）。验收标准：4 个数字卡数值与数据一致；趋势图按自然周聚合；排行按本月破戒次数降序。

### FR-05 记录历史查看

按主题查看破戒记录列表（日期、次数、备注），支持翻页或按需加载。验收标准：显示该主题全部记录，按日期倒序。

### FR-06 删除功能

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| 删除记录 | 可删除单条破戒记录，删除后统计同步更新 | Given 删除一条记录；When 返回首页；Then A3/A5/A6 及统计数值随之更新 |
| 删除主题 | 可删除主题卡，需二次确认，连带删除其全部记录 | Given 用户点删除主题；When 确认；Then 主题与记录一并删除，首页不再显示 |

## 八、非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 首页首屏渲染 ≤ 1.5s；查询走数据库条件过滤，不做全量拉取后前端筛选 |
| 兼容性 | 微信基础库 ≥ 2.2.3；适配主流 iOS / Android 机型 |
| 数据安全 | 云数据库权限「仅创建者可读写」，依赖 `_openid` 隔离多用户数据 |
| 可读性 | 卡片信息一屏可读，颜色对比满足基本可访问性 |
| 隐私 | 备注含用户自述内容，仅本人可见，不做上传分享 |

## 九、业务流程与状态流转

**破戒记录主流程**

```
进入首页 → 点击主题卡记录按钮 → 选择日期（默认今天）
→ 填写次数（默认1）与备注 → 保存 → 写入 checkins
→ 重新计算 A3/A5/A6 → 返回首页刷新
```

**达成判定状态机**

| 当前周期破戒次数 | 与上限 X 比较 | 状态 |
|---|---|---|
| ≤ X | 未超过 | 达成 / 正常 |
| > X | 超过 | 失败 / 已超限 |

> 状态为只读派生结果，随记录增删实时重算，不单独存储。

## 十、数据与埋点需求

**云数据库集合**（沿用已建集合，需补充字段）

`habits`（主题卡）

| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 标题 C1 |
| subtitle | string | 副标题 C2 |
| icon | string | emoji C3 |
| startDate | string | 开始日期 C4，格式 YYYY-MM-DD |
| periodType | string | 目标周期 C5：`day` / `week` / `month` |
| limit | number | 上限次数 X |
| order | number | 卡片排序 |
| createdAt | number | 创建时间戳 |

`checkins`（破戒记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| habitId | string | 所属主题 ID |
| date | string | 破戒日期 YYYY-MM-DD |
| count | number | 本次破戒次数（默认 1） |
| note | string | 备注 |
| createdAt | number | 创建时间戳 |

**统计口径**

| 指标 | 计算方式 |
|---|---|
| A5 距上次破戒天数 | 今天 - 最近一条 checkin 的 date；无记录时用 startDate |
| A6 周期破戒次数 | 按 periodType 过滤当前周期的 checkins，累加 count |
| 连续未破戒天数 | 同 A5 口径 |

**埋点（MVP 最小集）**：记录保存成功、主题新增、主题删除、统计页访问——各 1 个事件，含主题 ID 与时间戳。

## 十一、权限与安全要求

| 项 | 要求 |
|---|---|
| 数据隔离 | 云数据库集合权限「仅创建者可读写」，按 `_openid` 自动隔离 |
| 输入校验 | 次数必须为正整数；日期不得晚于今天；标题非空 |
| 删除保护 | 删除主题需二次确认 |
| 内容安全 | 备注为用户自述文本，仅本地可见、不公开，本期不引入内容审核 |

## 十二、异常处理清单

| 场景 | 处理 |
|---|---|
| 断网 / 云函数不可用 | 提示"网络异常，请重试"，不丢失已填表单 |
| 日期填未来 | 禁止，提示"日期不能晚于今天" |
| 次数填 0 或负数 | 禁止，提示"次数至少为 1" |
| 编辑页无对应主题 | 提示"主题不存在"，返回首页 |
| 无破戒记录 | A5 从开始日期起算；A3 全绿；统计显示 0 |
| 同一天重复记录 | 允许，次数累加，不做去重 |
