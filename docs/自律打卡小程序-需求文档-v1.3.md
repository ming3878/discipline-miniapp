## 二、背景与目标

**一句话定位**：这是一款「戒断型」自律工具。它不记录"完成了什么"，只记录"**破戒了几次**"，以"不超过上限"为达成标准——记录一次即破戒一次，没有记录就是没破戒。

| 项 | 内容 |
|---|---|
| 要解决的问题 | 用户需要对多个戒断主题（如戒烟、戒游戏、戒熬夜）的破戒行为做轻量记录，并直观看到"坚持了多久、这周破戒几次、有没有超标、整体趋势是否改善" |
| 目标用户 | 用户本人 + 小范围试用朋友（各自独立记录，本期不做互动） |
| 成功指标（建议，待确认） | ① 单次打卡路径 ≤ 3 次点击；② 7 日留存 ≥ 25%；③ 记录卡信息一屏可读，无需滚动 |

## 三、名词与术语

| 术语 | 定义 |
|---|---|
| 主题 / 记录卡 | 一个戒断对象（如"戒烟"），是记录与统计的基本单元 |
| 破戒 | 一次违反自律的行为。**记录一次 = 破戒一次；无记录 = 未破戒** |
| 破戒次数 | 某条记录或某周期内累计的破戒数量（同一天多条记录累加） |
| 上限 X 次 | 目标周期内允许的最大破戒次数，**X 为 ≥ 1 的正整数，不存在 0 次上限**；超过（> X）判为失败，等于（= X）算达成 |
| 目标周期 | 每天 / 每周 / 每月三选一，决定 A6 与达成次数的统计口径 |
| 当前周期 | 根据目标周期动态确定的统计区间（今日 / 本周 / 本月），均按自然日 / 自然周 / 自然月划分 |
| 周期单元 | 目标周期下的一个最小统计单位（一个自然日 / 一个自然周 / 一个自然月） |
| 达成 | 某个**已结束**的周期单元内，破戒次数 ≤ 上限 X |
| C4 起点 | 主题的开始日期，是所有时间统计的统一起点：最早周期从它所在周期算起，最长已戒也从它起算 |

## 四、需求范围

**本期包含**
- 记录卡列表（7 个字段展示）
- 破戒记录页（日期可调、次数、备注，同日多次叠加）
- 主题卡的新增与编辑（编辑 C5 后历史全量重算）
- **单卡统计页**：习惯数据总览 6 项 + 月历破戒图
- **总体统计页**：总体数据总览 4 项 + 月度图形 2 个
- **记录明细页**：按主题查看、按月筛选、单条删除

**本期不包含（明确排除）**
- 账号体系、登录注册
- 好友互动、排行榜、分享（个人主体审核红线，且用户未提出）
- 定时提醒 / 推送
- 记录的编辑（只做删除，见 FR-07）
- 数据导出
- 主题归档 / 停用（本期所有主题均为进行中）
- **达成成功率及达成率走势图**（v1.2 移除，相关统计只在单卡以"达成次数"呈现）

## 五、统计方案（已确认）

统计分两个维度，页面与数据完全分开：

| 维度 | 页面 | 入口 | 内容 |
|---|---|---|---|
| 维度一 · 单卡 | 单卡统计页 | 首页点击卡片标题或空白区域（A7 记录按钮保持独立） | 习惯数据总览 6 项 + 月历破戒图 + 记录明细入口 |
| 维度二 · 总体 | 总体统计页 | 底部 tabBar「统计」 | 总体数据 4 项 + 月度图形 2 个 |

> 原 v1.0 的「近 8 周破戒趋势」调整为月度口径；「本月主题排行」并入总体月度图形②；「达成成功率」与「达成率走势」按用户要求移除。

## 六、用户角色与使用场景

**用户画像**（基于用户口述，非调研数据）：注重自我管理、希望量化戒断进度、愿意手动记录破戒行为的个人用户。

| 场景 | 描述 |
|---|---|
| S1 破戒后记录 | 打开小程序 → 进入对应主题卡 → 点记录按钮 → 选日期（默认今天）→ 填次数与原因 → 保存 |
| S2 每日查看 | 打开首页，扫一眼各主题卡的 A3~A6，判断本周状态 |
| S3 新建主题 | 决定戒断新习惯 → 新增记录卡 → 填标题/副标题/emoji/开始日期/目标周期与上限 |
| S4 单卡复盘 | 点击某主题卡 → 查看习惯数据总览与月历 → 判断该主题的长期趋势与达成次数 |
| S5 历史清理 | 从单卡统计进入记录明细 → 按月筛选 → 删除误记记录 → 统计自动重算 |
| S6 整体复盘 | 打开总体统计页 → 看累计破戒趋势与主题对比 → 判断整体是否在改善 |

### FR-01 记录卡列表（首页）

展示所有主题卡，每卡包含以下 7 个字段。

**空态**：无任何主题时，页面展示引导卡片「还没有主题，点此创建第一个」及操作按钮，点击进入主题管理页（UI 实现时一并补齐，不单列功能编号）。

| 字段 | 编号 | 需求描述 | 验收标准（Given/When/Then） |
|---|---|---|---|
| 标题 + emoji | A1 | 卡片标题，emoji 显示在标题前 | Given 标题"戒烟"、emoji 🚭；When 进入首页；Then 卡片首行显示"🚭 戒烟" |
| 副标题 | A2 | 主题的说明文字 | Given 副标题"为了健康"；When 进入首页；Then 标题下方显示该文字；为空时不占位 |
| 一周达成情况 | A3 | **固定展示周一至周日 7 天**，每天一个色块，**与目标周期无关**，仅表达"这周哪天破戒了" | Given 主题 C4 为周三、本周三/周五有破戒；When 进入首页；Then 周一/周二为灰色（未开始），周三/周五为破戒色，周四为未破戒色，未来日期为灰色 |
| 周期上限状态 | A4 | 显示当前周期是否超过上限，用状态标识（正常 / 已超限） | Given 周上限 3 次、本周已破戒 4 次；When 进入首页；Then 状态显示"已超限" |
| 距上次破戒天数 | A5 | 距最近一次破戒记录的自然日天数；**无任何破戒记录时，从 C4 起算** | Given 最近破戒为 3 天前；When 进入首页；Then 显示"3 天"；今天破戒则显示"0 天" |
| 周期破戒次数 / 上限 | A6 | **跟随 C5 目标周期切换**：每天→今日次数/日上限；每周→本周次数/周上限；每月→本月次数/月上限 | Given 月上限 10 次、本月已破戒 6 次；When 进入首页；Then 显示"6 / 10" |
| 记录按钮 | A7 | 每张卡一个"记录"按钮，点击进入该主题的记录页 | Given 任一主题卡；When 点击记录按钮；Then 跳转至该主题的记录页 |

**卡片点击行为**：点击卡片标题或空白区域 → 进入该主题的单卡统计页；A7 记录按钮事件独立，不触发卡片跳转。

**A3 / 月历颜色语义**（五态，已确认）：

| 日期状态 | 颜色 |
|---|---|
| 破戒日 | 红色系（破戒次数越多颜色越深） |
| 已过去的未破戒日 | 绿色 |
| 今天且未破戒 | 蓝色（高亮） |
| 未来日期 | 灰色 |
| **C4 开始日期之前** | **灰色（与未来日期同色）** |

### FR-02 破戒记录页

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| B1 | 打卡日期，默认当天，可调；**不得早于 C4 开始日期**（C4 是所有时间的起点，破戒记录只能发生在起点当天或之后） | Given C4=2026-11-01；When 打开记录页；Then 日期选择器禁用 11-01 之前的所有日期，最早可选 11-01 |
| B2 | 打卡数据 = 违反自律次数，默认 1，可修改，最小为 1 | Given 一次破戒；When 不修改；Then 记 1 次；改为 3 则记 3 次；填 0 或负数禁止保存 |
| B3 | 备注，自定义填写原因 | Given 输入"熬夜打游戏"；When 保存；Then 备注随记录存储并可在记录明细页查看 |
| 叠加规则 | 同一天可多次记录，破戒次数累加 | Given 同日已记 1 次、再记 2 次；When 统计当日；Then 当日破戒次数为 3 次 |

### FR-03 新增 / 编辑记录卡

| 编号 | 字段 | 需求描述 | 验收标准 |
|---|---|---|---|
| C1 | 标题 | 必填，非空 | 为空时禁止保存并提示 |
| C2 | 副标题 | 选填 | 可留空 |
| C3 | emoji 图标 | 从 emoji 选择器中选，展示在标题前 | 选择后标题前正确渲染 |
| C4 | 从哪天开始戒 | 日期选择，默认今天，不得晚于今天；**编辑时不得选晚于该主题最早破戒记录的日期**（保证已有记录都不早于新起点） | 是所有时间统计的统一起点；最早破戒点 = 第一条破戒记录的日期，必然 ≥ C4 |
| C5 | 目标计算方式 | 每天 / 每周 / 每月 不超过 X 次（三选一），**X 为 ≥ 1 的正整数，不设 0** | Given 选"每月"、X=10；When 保存；Then A6 显示"本月累计/10"，达成判定按月口径；X 填 0 禁止保存 |
| C5 变更规则 | 编辑 C5 后全量重算 | 修改周期类型或上限后，**全部历史记录按新 C5 重新计算达成次数**，不保留旧口径快照 | Given 历史按周目标已达成 15 次；When 改为月目标；Then 达成次数按新口径重算，编辑前提示"修改后历史统计将按新目标重算" |

> X 从 1 起算：完全戒断场景也设为 1（按原定义，破戒 1 次仍属"不超过上限"，> 1 判失败）。表单需明示"上限至少 1 次，破戒次数超过上限才算失败"。

### FR-04 单卡统计页

**4.1 习惯数据总览（6 项）**

| 编号 | 指标 | 口径 | 验收标准 |
|---|---|---|---|
| 1.1 | 习惯始于 | 取 C4 开始日期 | 显示值与卡片配置的开始日期一致 |
| 1.2 | 当前已戒 | 同 A5：今天 − 最近一条破戒记录日期；无记录则从 C4 起算 | Given 最近破戒 3 天前；Then 显示"3 天" |
| 1.3 | 最长已戒 | 将 **[C4 开始日期, 全部破戒日期去重升序, 今天]** 组成时间序列，取**相邻两点间的最大自然日差**。C4 是统一起点，因此即使只有 1 条破戒记录也能算出区间；0 条记录时区间为 [C4, 今天] | Given C4=11-01、破戒日=11-10 和 11-25、今天=11-24；Then 区间为 9/15/… 取最大值 |
| 1.4 | 合计破戒 X 次 | 该主题全部记录 count 之和 | Given 3 条记录分别为 1/2/4 次；Then 显示"7 次" |
| 1.5 | 达成目标 X 次 | 按 C5 周期类型，从 C4 所在自然周期开始枚举到上一个已结束周期，统计破戒次数 ≤ 上限的周期个数；**进行中的当前周期不计入** | Given 周目标上限 2 次、已完成 20 周中 15 周未超标；Then 显示"达成 15 次" |
| 1.6 | 记录明细 | 入口按钮，跳转记录明细页（FR-06） | Given 点击记录明细；When 跳转；Then 显示该主题全部记录 |

## 八、非功能需求

| 类别 | 要求 |
|---|---|

| 隐私 | 备注含用户自述内容，仅本人可见，不做上传分享 |
| 一致性 | 同名指标（A5 / 1.2、A6 / 1.5、累计次数）在首页、单卡统计、总体统计中口径一致，数值不得矛盾 |

## 九、业务流程与状态流转

**破戒记录主流程**
```
首页 → 点击主题卡记录按钮 → 选择日期（默认今天，不早于 C4）
→ 填写次数（默认 1）与备注 → 保存 → 写入 checkins
→ 重算 A3/A4/A5/A6 → 返回首页刷新
```

**单卡统计查看流程**
```
首页 → 点击卡片标题/空白区 → 单卡统计页
→ 查看 6 项总览 + 月历 → 点击记录明细 → 按月筛选 → 删除误记记录
→ 统计实时重算
```

**达成判定状态机**

| 当前周期破戒次数 | 与上限 X 比较 | 状态 |
|---|---|---|
| ≤ X（X ≥ 1） | 未超过 | 达成 / 正常 |
| > X | 超过 | 失败 / 已超限 |

> 状态为只读派生结果，随记录增删实时重算，不单独存储。X 最小为 1。

| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 标题 C1 |
| subtitle | string | 副标题 C2 |
| icon | string | emoji C3 |
| startDate | string | 开始日期 C4，格式 YYYY-MM-DD |
| periodType | string | 目标周期 C5：`day` / `week` / `month` |
| limit | number | 上限次数 X，取值范围 ≥ 1 |
| order | number | 卡片排序 |
| createdAt | number | 创建时间戳 |
| updatedAt | number | 最后修改时间戳（C5 变更时更新） |

`checkins`（破戒记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| habitId | string | 所属主题 ID |
| date | string | 破戒日期 YYYY-MM-DD |
| count | number | 本次破戒次数（默认 1，≥ 1） |
| note | string | 备注 |
| createdAt | number | 创建时间戳 |

建议为 `checkins` 建立 `habitId + date` 复合索引，提升按主题与月份聚合的查询效率。

**统计口径汇总**

| 指标 | 计算方式 |
|---|---|
| A5 / 1.2 当前已戒 | 今天 − MAX(checkin.date)；无记录时用 startDate |
| 1.3 最长已戒 | 序列 [startDate, 各破戒日期去重升序, 今天]，取相邻日期差最大值 |
| A6 周期破戒次数 | 按当前 periodType 过滤当前周期的 checkins，累加 count；周期按自然日 / 自然周 / 自然月划分 |
| 1.5 达成次数 | 从 startDate 所在自然周期起枚举到上一完整周期，逐周期判断 count ≤ limit，统计为真的数量；**C5 变更后按新值全量重算** |
| 总体当前连续未破戒天数 | 今天 − MAX(所有 checkin.date)；无记录时取 MIN(所有 startDate) |
| 总体累计破戒次数 | SUM(全部 checkins.count) |
| 月度趋势 | 按 date 的自然月分组，累加 count；展示最近 6 个月 |

**埋点（MVP 最小集）**：记录保存成功、主题新增、主题编辑、主题删除、单卡统计页访问、总体统计页访问、记录明细页访问、记录删除——各 1 个事件，含主题 ID（如适用）与时间戳。

## 十二、异常处理清单

| 场景 | 处理 |
|---|---|
| 断网 / 云函数不可用 | 提示"网络异常，请重试"，不丢失已填表单 |
| 日期填未来或早于 C4 | 禁止，提示"日期需在开始日期与今天之间" |
| 次数或上限填 0 / 负数 | 禁止，提示"次数至少为 1" |
| 编辑页无对应主题 | 提示"主题不存在"，返回首页 |
| 无破戒记录 | A5 从 C4 起算；A3 全绿（C4 之前灰）；1.3 显示 [C4, 今天] 天数；达成次数为 0；总体统计显示 0 或空态 |
| 同一天重复记录 | 允许，次数累加，不做去重；1.3 计算时同一天视为一个日期点 |
| 月份切换超出范围 | 早于 C4 所在月、晚于当前月的月份不可选 |
| 数据删除后图表为空 | 图表显示空态而非报错 |
| C5 变更后数值大幅变化 | 编辑时提前提示，用户确认后保存并重算 |

## 十五、附录

**用户故事（核心 4 条）**

1. 作为用户，我想要快速记录一次破戒，以便不打断当下、又能留下数据。
2. 作为用户，我想要在首页一眼看到各主题本周破戒情况与连续天数，以便判断自律状态。
3. 作为用户，我想要查看单主题的历史最长戒断与月历，以便看清该主题的长期走势。
4. 作为用户，我想要看总体累计趋势与主题对比，以便判断整体是否在改善。
