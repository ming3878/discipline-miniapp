## 二、背景与目标

**一句话定位**：这是一款「戒断型」自律工具。它不记录"完成了什么"，只记录"**破戒了几次**"，以"不超过上限"为达成标准——记录一次即破戒一次，没有记录就是没破戒。

| 项 | 内容 |
|---|---|
| 要解决的问题 | 用户需要对多个戒断主题（如戒烟、戒游戏、戒熬夜）的破戒行为做轻量记录，并直观看到"坚持了多久、这周破戒几次、有没有超标、整体趋势是否改善" |
| 目标用户 | 用户本人 + 小范围试用朋友（各自独立记录，本期不做互动） |
| 成功指标（建议，待确认） | ① 单次打卡路径 ≤ 3 次点击；② 7 日留存 ≥ 25%；③ 记录卡信息一屏可读，无需滚动 |

## 三、名词与术语

| 术语 | 定义 |
|---|---|
| 主题 / 记录卡 | 一个戒断对象（如"戒烟"），是记录与统计的基本单元 |
| 破戒 | 一次违反自律的行为。**记录一次 = 破戒一次；无记录 = 未破戒** |
| 破戒次数 | 某条记录或某周期内累计的破戒数量（同一天多条记录累加） |
| 上限 X 次 | 目标周期内允许的最大破戒次数。**超过（> X）判为失败；等于（= X）算达成** |
| 目标周期 | 每天 / 每周 / 每月三选一，决定 A6、达成次数与达成成功率的统计口径 |
| 当前周期 | 根据目标周期动态确定的统计区间（今日 / 本周 / 本月） |
| 周期单元 | 目标周期下的一个最小统计单位（一天 / 一个自然周 / 一个自然月） |
| 达成 | 某个**已结束**的周期单元内，破戒次数 ≤ 上限 X |

## 四、需求范围

**本期包含**
- 记录卡列表（7 个字段展示）
- 破戒记录页（日期可调、次数、备注，同日多次叠加）
- 主题卡的新增与编辑
- **单卡统计页**：习惯数据总览 6 项 + 月历破戒图
- **总体统计页**：总体数据总览 5 项 + 月度图形 3 个
- **记录明细页**：按主题查看、按月筛选、单条删除

**本期不包含（明确排除）**
- 账号体系、登录注册
- 好友互动、排行榜、分享（个人主体审核红线，且用户未提出）
- 定时提醒 / 推送
- 记录的编辑（只做删除，见 FR-07）
- 数据导出
- 主题归档 / 停用（本期所有主题均为进行中）

## 六、用户角色与使用场景

**用户画像**（基于用户口述，非调研数据）：注重自我管理、希望量化戒断进度、愿意手动记录破戒行为的个人用户。

| 场景 | 描述 |
|---|---|
| S1 破戒后记录 | 打开小程序 → 进入对应主题卡 → 点记录按钮 → 选日期（默认今天）→ 填次数与原因 → 保存 |
| S2 每日查看 | 打开首页，扫一眼各主题卡的 A3~A6，判断本周状态 |
| S3 新建主题 | 决定戒断新习惯 → 新增记录卡 → 填标题/副标题/emoji/开始日期/目标周期与上限 |
| S4 单卡复盘 | 点击某主题卡 → 查看习惯数据总览与月历 → 判断该主题的长期趋势 |
| S5 历史清理 | 从单卡统计进入记录明细 → 按月筛选 → 删除误记记录 → 统计自动重算 |
| S6 整体复盘 | 打开总体统计页 → 看成功率、全清天数与 3 个月度图形 → 判断整体是否在改善 |

## 七、功能需求（含验收标准）

### FR-01 记录卡列表（首页）

展示所有主题卡，每卡包含以下 7 个字段：

| 字段 | 编号 | 需求描述 | 验收标准（Given/When/Then） |
|---|---|---|---|
| 标题 + emoji | A1 | 卡片标题，emoji 显示在标题前 | Given 标题"戒烟"、emoji 🚭；When 进入首页；Then 卡片首行显示"🚭 戒烟" |
| 副标题 | A2 | 主题的说明文字 | Given 副标题"为了健康"；When 进入首页；Then 标题下方显示该文字；为空时不占位 |
| 一周达成情况 | A3 | **固定展示周一至周日 7 天**，每天一个色块，**与目标周期无关**，仅表达"这周哪天破戒了" | Given 本周三、周五有破戒；When 进入首页；Then 周三/周五为破戒色，其余已过日期为未破戒色，未来日期为未来色 |
| 周期上限状态 | A4 | 显示当前周期是否超过上限，用状态标识（正常 / 已超限） | Given 周上限 3 次、本周已破戒 4 次；When 进入首页；Then 状态显示"已超限" |
| 距上次破戒天数 | A5 | 距最近一次破戒记录的自然日天数；**无任何破戒记录时，从"开始日期"起算** | Given 最近破戒为 3 天前；When 进入首页；Then 显示"3 天"；今天破戒则显示"0 天" |
| 周期破戒次数 / 上限 | A6 | **跟随 C5 目标周期切换**：每天→今日次数/日上限；每周→本周次数/周上限；每月→本月次数/月上限 | Given 月上限 10 次、本月已破戒 6 次；When 进入首页；Then 显示"6 / 10" |
| 记录按钮 | A7 | 每张卡一个"记录"按钮，点击进入该主题的记录页 | Given 任一主题卡；When 点击记录按钮；Then 跳转至该主题的记录页 |

**卡片点击行为**：点击卡片标题或空白区域 → 进入该主题的单卡统计页；A7 记录按钮事件独立，不触发卡片跳转。

**A3 颜色语义**（按默认方案实现，可调整）：

| 日期状态 | 颜色 |
|---|---|
| 破戒日 | 红色系（破戒次数越多颜色越深） |
| 已过去的未破戒日 | 绿色 |
| 今天且未破戒 | 蓝色（高亮） |
| 未来日期 | 浅灰 |

### FR-02 破戒记录页

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| B1 | 打卡日期，默认当天，可调 | Given 今天 2026-11-24；When 打开记录页；Then 日期默认今天，且可改为其他日期 |
| B2 | 打卡数据 = 违反自律次数，默认 1，可修改 | Given 一次破戒；When 不修改；Then 记 1 次；改为 3 则记 3 次 |
| B3 | 备注，自定义填写原因 | Given 输入"熬夜打游戏"；When 保存；Then 备注随记录存储并可在记录明细页查看 |
| 叠加规则 | 同一天可多次记录，破戒次数累加 | Given 同日已记 1 次、再记 2 次；When 统计当日；Then 当日破戒次数为 3 次 |

### FR-03 新增 / 编辑记录卡

| 编号 | 字段 | 需求描述 | 验收标准 |
|---|---|---|---|
| C1 | 标题 | 必填，非空 | 为空时禁止保存并提示 |
| C2 | 副标题 | 选填 | 可留空 |
| C3 | emoji 图标 | 从 emoji 选择器中选，展示在标题前 | 选择后标题前正确渲染 |
| C4 | 从哪天开始戒 | 日期选择，默认今天 | 用于 A5 无破戒记录时的起算点，并作为单卡统计的起点 |
| C5 | 目标计算方式 | 每天 / 每周 / 每月 不超过 X 次（三选一），X 为正整数 | Given 选"每月"、X=10；When 保存；Then A6 显示"本月累计/10"，达成判定按月口径 |

### FR-04 单卡统计页

**4.1 习惯数据总览（6 项）**

| 编号 | 指标 | 口径 | 验收标准 |
|---|---|---|---|
| 1.1 | 习惯始于 | 取 C4 开始日期 | 显示值与卡片配置的开始日期一致 |
| 1.2 | 当前已戒 | 同 A5：今天 − 最近一条破戒记录日期；无记录则从 C4 起算 | Given 最近破戒 3 天前；Then 显示"3 天" |
| 1.3 | 最长已戒 | **历史中所有相邻两个破戒日期之间的最大自然日差**；不含开始日期与今天；同一天多条记录视为同一天；破戒记录少于 2 条时显示"—"并提示"至少 2 次破戒后可见" | Given 破戒日期为 11-01、11-10、11-25；Then 最长已戒 = 9 天 |
| 1.4 | 合计破戒 X 次 | 该主题全部记录 count 之和 | Given 3 条记录分别为 1/2/4 次；Then 显示"7 次" |
| 1.5 | 达成目标 X 次 | 按 C5 周期类型，统计**已完成周期单元**中破戒次数 ≤ 上限的个数；进行中的当前周期不计入 | Given 周目标上限 2 次、已完成 20 周中 15 周未超标；Then 显示"达成 15 次" |
| 1.6 | 记录明细 | 入口按钮，跳转记录明细页（FR-06） | Given 点击记录明细；When 跳转；Then 显示该主题全部记录 |

**4.2 月历破戒图**

| 项 | 需求 |
|---|---|
| 形态 | 整月日历网格，按周排列（周一为首列），可前后切换月份 |
| 颜色 | 沿用 A3 语义：破戒日红色（按当日破戒次数深浅）、已过未破戒日绿色、今天蓝色、未来日期浅灰 |
| 交互 | 点击某日可查看当日破戒次数与备注摘要；无记录日提示"当日未破戒" |
| 范围 | 不早于 C4 开始日期的月份不显示数据（显示空态）；不晚于当前月 |

### FR-05 总体统计页

**5.1 总体数据总览（5 项）**

| 指标 | 口径 | 展示形式 |
|---|---|---|
| 达成成功率 | 所有主题已完成周期单元中，达成周期数 ÷ 已完成周期总数 × 100%（不同周期类型按周期单元累加混算） | 百分比数字卡 |
| 当前连续未破戒天数 | **全局最近一次破戒记录（所有主题中最近发生的一条）到今天的自然日天数**；无任何记录时取所有主题中最早的 C4 开始日期 | 大数字卡 |
| 累计破戒总次数 | 全部主题全部记录的 count 之和 | 数字卡 |
| 进行中主题数 | 已创建主题总数（本期无归档，即全部主题） | 数字卡 |
| 坚持最久主题 | 单卡 1.2「当前已戒」数值最大的主题名称及其天数 | 数字卡 |

> 「当前连续未破戒天数」采用全局口径：任一主题破戒都会重置，等价于"全主题全清天数"，与「坚持最久主题」形成互补而非重复。

**5.2 月度图形（3 个）**

| 编号 | 图形 | 口径 | 展现 |
|---|---|---|---|
| ① | 近 6 个月破戒次数趋势 | 按自然月汇总所有主题的破戒次数 | 柱状图，横轴月份、纵轴次数 |
| ② | 近 6 个月达成率走势 | 按月统计：日目标主题按该月达成天数/总天数，周目标主题按该月内达成的周数/周数（周归属按周一所在月），月目标主题按该月是否达成；三类结果汇总为比率 | 折线图，横轴月份、纵轴百分比 |
| ③ | 本月各主题破戒对比 | 按主题统计本月破戒次数，降序排列 | 横向条形列表，显示次数 |

### FR-06 记录明细页

| 项 | 需求 |
|---|---|
| 数据来源 | 指定主题的 `checkins` 全部记录 |
| 展示字段 | 破戒日期、次数、备注摘要 |

### FR-07 删除功能

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| 删除记录 | 可删除单条破戒记录，删除后所有统计同步更新 | Given 删除一条记录；When 返回；Then 首页 A3/A5/A6、单卡统计 6 项、总体统计 5 项及 3 个图形均随之重算 |

## 八、非功能需求

| 类别 | 要求 |
|---|---|

| 可读性 | 卡片信息一屏可读；统计数字与图表标签对比满足基本可访问性 |
| 隐私 | 备注含用户自述内容，仅本人可见，不做上传分享 |
| 一致性 | 同名指标（A5 / 1.2、A6 / 1.5、累计次数）在首页、单卡统计、总体统计中口径一致，数值不得矛盾 |

## 九、业务流程与状态流转

**破戒记录主流程**
```
首页 → 点击主题卡记录按钮 → 选择日期（默认今天）
→ 填写次数（默认1）与备注 → 保存 → 写入 checkins
→ 重算 A3/A4/A5/A6 → 返回首页刷新
```

**单卡统计查看流程**
```
首页 → 点击卡片标题/空白区 → 单卡统计页
→ 查看 6 项总览 + 月历 → 点击记录明细 → 按月筛选 → 删除误记记录
→ 统计实时重算
```

**达成判定状态机**

| 当前周期破戒次数 | 与上限 X 比较 | 状态 |
|---|---|---|
| ≤ X | 未超过 | 达成 / 正常 |
| > X | 超过 | 失败 / 已超限 |

> 状态为只读派生结果，随记录增删实时重算，不单独存储。

## 十、数据与埋点需求

**云数据库集合**（沿用已建集合，字段无需新增）

`habits`（主题卡）

| 字段 | 类型 | 说明 |
|---|---|---|
| name | string | 标题 C1 |
| subtitle | string | 副标题 C2 |
| icon | string | emoji C3 |
| startDate | string | 开始日期 C4，格式 YYYY-MM-DD |
| periodType | string | 目标周期 C5：`day` / `week` / `month` |
| limit | number | 上限次数 X |
| order | number | 卡片排序 |
| createdAt | number | 创建时间戳 |

`checkins`（破戒记录）

| 字段 | 类型 | 说明 |
|---|---|---|
| habitId | string | 所属主题 ID |
| date | string | 破戒日期 YYYY-MM-DD |
| count | number | 本次破戒次数（默认 1） |
| note | string | 备注 |
| createdAt | number | 创建时间戳 |

建议为 `checkins` 建立 `habitId + date` 复合索引，提升按主题与月份聚合的查询效率。

**统计口径汇总**

| 指标 | 计算方式 |
|---|---|
| A5 / 1.2 当前已戒 | 今天 − MAX(checkin.date)；无记录时用 startDate |
| 1.3 最长已戒 | 将某主题破戒日期去重升序排列，取相邻日期差的最大值；记录数 < 2 时无值 |
| A6 周期破戒次数 | 按 periodType 过滤当前周期的 checkins，累加 count |
| 1.5 达成次数 | 从 startDate 到今天，枚举所有**已结束**周期单元，逐个判断 count ≤ limit，统计为真的数量 |
| 总体达成成功率 | 全部主题的达成周期数之和 ÷ 全部主题已完成周期数之和 |
| 总体当前连续未破戒天数 | 今天 − MAX(所有 checkin.date)；无记录时取 MIN(所有 startDate) |
| 总体累计破戒次数 | SUM(全部 checkins.count) |
| 月度趋势 | 按 date 的自然月分组，累加 count；展示最近 6 个月 |

**埋点（MVP 最小集）**：记录保存成功、主题新增、主题删除、单卡统计页访问、总体统计页访问、记录明细页访问、记录删除——各 1 个事件，含主题 ID（如适用）与时间戳。

## 十一、权限与安全要求

| 项 | 要求 |
|---|---|
| 数据隔离 | 云数据库集合权限「仅创建者可读写」，按 `_openid` 自动隔离 |
| 输入校验 | 次数必须为正整数；日期不得晚于今天；标题非空 |
| 删除保护 | 删除主题、删除记录均需二次确认 |
| 内容安全 | 备注为用户自述文本，仅本人可见、不公开，本期不引入内容审核 |

## 十二、异常处理清单

| 场景 | 处理 |
|---|---|
| 断网 / 云函数不可用 | 提示"网络异常，请重试"，不丢失已填表单 |
| 日期填未来 | 禁止，提示"日期不能晚于今天" |
| 次数填 0 或负数 | 禁止，提示"次数至少为 1" |
| 编辑页无对应主题 | 提示"主题不存在"，返回首页 |
| 无破戒记录 | A5 从开始日期起算；A3 全绿；1.3 显示"—"；达成次数为 0；总体统计显示 0 或空态 |
| 破戒记录不足 2 条 | 1.3 显示"—"并提示"至少 2 次破戒后可见" |
| 同一天重复记录 | 允许，次数累加，不做去重；1.3 计算时同一天视为一个日期点 |
| 主题开始日期在未来 | 禁止选择未来日期 |
| 月份切换超出范围 | 早于开始日期、晚于当前月的月份不可选 |
| 数据删除后图表为空 | 图表显示空态而非报错 |

## 十五、附录

**用户故事（核心 4 条）**

1. 作为用户，我想要快速记录一次破戒，以便不打断当下、又能留下数据。
2. 作为用户，我想要在首页一眼看到各主题本周破戒情况与连续天数，以便判断自律状态。
3. 作为用户，我想要查看单主题的历史最长戒断与月历，以便看清该主题的长期走势。
4. 作为用户，我想要看总体成功率与月度图形，以便判断整体是否在改善。
